will learn how to automatically send an email when a lead subscribes. what you'll need: a systeme.io account a sales funnel an opt-in page 1. creating an automation rule select your opt-in page from the funnel list on the left, then click the automation rules tab (1) and add rule (2). click the + icon add a new trigger (3). select funnel step form subscribed (4). click the + icon to add an action (5). select send email (6). tip: you can also add the "add a tag" action to segment these contacts. to learn more how to create a tag, check out our dedicated help article: how to create a tag . 2. creating an email click the + icon to create a new email (7). once finished, click save rule (8). the new rule is now active (9). a. editing the email click the three-dot menu of the rule you created, then select edit automation rule (10). click the pencil icon (11) to edit the email. you can attach files (e.g., pdfs) to your emails (12) and insert personalization substitutes (variables) that are automatically replaced with each contact's actual information (13). once you've finished editing the email, click save (14) to save your changes. click save rule (15) again to save the updated automation rule. to return to the main automation rules list, click the back (16) button. you can also manage existing rules by clicking the three-dots menu next to a rule, where you can edit, disable, or delete it (17). 3. testing the email automation we recommend testing your funnel by registering on your own opt-in page. if the email isn't sent or the contact isn't added, contact the systeme.io support team here . notes: the form button's action must be set to submit form for the automation rule to be triggered automatically after submission. to learn more, check out the following help article: how to set up a button . to improve email deliverability, we restrict the size of file attachments to 5 mb. if your file is larger than 5 mb, you will need to compress it before adding it. did this answer your question? last updated on november 10, 2026
