# Consigne d'un lot de production (session de production Claude)

Texte donné par la régie à chaque session neuve de production (2 vidéos, une par une ; décision de l'utilisateur du 22/11 : Sonnet à effort réduit, `create_session` model claude-sonnet-5-5 et effort medium). Une seule session de production à la fois (`data/history.json` et le claim sont partagés) : la régie crée la suivante quand la précédente a écrit « Lot terminé ». PAS de session pré-chauffée qui attend un message « Go » : une session n'obéit qu'à son prompt initial et refuse, à juste titre, de lancer des publications sur le seul message d'une autre session (constaté le 22/11). Le prompt commence donc par « COMMENCE TOUT DE SUITE, sans attendre de message » et donne la conduite à tenir devant la fausse alerte « commits non poussés » d'un clone partiel (ne rien réparer, `git fetch --deepen=100` puis `git merge --ff-only`). Les marques
`<N>`, `<CRENEAUX>`, `<JOURNAL>` et `<SUJETS>` sont remplacées au lancement ; le numéro de la série vient toujours de
`serie:slot`, jamais d'une liste mémorisée. Les défauts listés à l'étape 2 sont ceux que la relecture indépendante a relevés
le 22/11/2026 sur les premières vidéos.
